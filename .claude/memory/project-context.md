# Контекст проекта

## Что за проект
- Название: ОМУТ. Слоган: «В чёрном омуте черти водятся»
- Одной фразой: цифровая (браузер) дуэльная карточная игра против ИИ-бота, общая колода, поле: 2 линии (моя и соперника) по 5 квадратных миров, в каждом мире 2 карты; мир бьёт мир напротив; монеты как ресурс.
- Владелец: пользователь (Дмитрий)
- Статус: концепт (GDD написан)

## Ключевые решения
- Сеттинг: микс славянской мифологии, тёмного фэнтези, морских чудищ/нежити/огненной магии.
- Свет / Тьма / Нейтраль — метка на карте для синергий, НЕ команды игроков. Колода одна, раздача рандом, первый ход — жребий.
- Жизни игрока 25 (настройка 10–40). Монеты: доход + награда за убийство + сжечь карту (+1) + затаиться (+1).
- Типы: Существо (Люди/Нечисть/Чудища/Нежить), Строение, Чары, Проклятие, Оберег. Редкость: обычная (серый), редкая (синий), эпическая (багрянец), легендарная (золото).
- 50 уникальных карт, 80 в колоде.

## Решения v2 (2026-10-29)
- 6 миров, на столе 5 (перемешиваются): Явь=Люди, Навь=Нежить, Чаща=Нечисть, Пучина=Чудища, Пекло=Бесы, Омут=любой класс.
- Правило класса (уточнено 2026-10-29): любое существо можно ставить в любой мир, первая карта без ограничений. Пара в мире: либо один класс, либо одна из карт родного класса мира. Нельзя два разных чужих класса. В Омуте — только пара одного класса.
- Запланировано (ещё не сделано в omut-app.html): перетаскивание карт из руки, рука соперника рубашкой над его полем, карты подглядывания (рука соперника, верх Омута), раздел помощи. Движок в omut-app.html пока работает по старому правилу класса.
- Атака по любой карте мира напротив; Приоритет заставляет бить только его; пустой мир → урон в жизни игрока (25).
- Награда за убийство 0–5 по силе карты, не по редкости; 3–4 карты-щита за 0.
- Без ваншотов; чары: похищение жизни, уничтожить одну карту, копия карты с поля («Пустой лик»).
- Визуальный концепт: https://claude.ai/artifact/Lsx9rexQbABwg3WmG5B9Em (файл concept/omut-visual.html). GDD ещё не обновлён под v2.
- Концепт приложения: concept/omut-app.html (меню, жребий, замена, стол с ботом, переворот карт, бестиарий, правила).
- Платформа (решение 2026-10-29): мобильный сайт в первую очередь. Весь визуал и интерфейс проектируются под телефон (ширина ~390px, вертикальный экран, управление пальцем, перетаскивание из руки), десктоп вторичен.

Референсы: concept/assets/src/.

## Итерация 2 (2026-11-01) — по фидбеку пользователя
- Автобой: существа бьют сами в конце каждого хода (state.autoAttack, autoTarget/plannedAttacks в движке). Ручной атаки нет.
- Правило пары изменено пользователем: одна карта — в любой мир; пара — только если хотя бы одна карта родного класса мира (два чужих, даже одного класса, нельзя). Омут оставлен: пара одного класса (пользователь про Омут не говорил).
- Новое действие Move: перетащить своё существо в другой мир, раз за ход. Таймер хода (по умолчанию 60 с).
- Визуал: вода/разделение экрана убраны (пользователь: «забудь про него»); фон меню — Навь; иконки векторные (src/game/icons.ts); шрифты Golos Text + Ruslan Display вместо Tiny5; скругления вместо срезанных углов; рендер Z≥2.
