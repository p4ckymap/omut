# Известные проблемы

> Найденные, но ещё не исправленные баги, уязвимости уровня MEDIUM/LOW, технический долг. Закрытые — удалять (история в git).

## Формат
```
### <Короткое название>
Серьёзность: high / medium / low · Найдено: YYYY-MM-DD · Кем: <агент>
Где: файл:строка / модуль
Суть и сценарий:
Обход (если есть):
План исправления:
```

## Системные
### Субагенты не могут вызывать других субагентов
Серьёзность: low (ограничение платформы Claude Code)
Суть: цепочку агентов запускает основная сессия (оркестратор), а не сами агенты.
Обход: агент в отчёте пишет «нужен X для Y», оркестратор вызывает X.
