# ОМУТ

Дуэльная карточная игра против бота в браузере телефона. Тёмная славянская мифология,
пиксельный стиль. «В чёрном омуте черти водятся».

Phaser 3.90 + TypeScript + Vite. Правила — `docs/TZ-omut.md` и `docs/stage1-decisions.md`.

## Запуск

```powershell
npm.cmd ci --cache .npm-cache
npm.cmd run dev
```

На компьютере: http://localhost:5186/. С телефона в той же Wi-Fi сети: адрес из строки
`Network` в выводе Vite (например http://192.168.50.45:5186/). Шрифты (Golos Text, Ruslan Display)
лежат в проекте (`@fontsource`), интернет не нужен.

## Как играть (коротко)

- **Поставить карту** — перетащи из руки в золотое место (или коснись карты, потом места). Цена — монета в углу карты.
- **Пара в мире** — одна карта может стоять где угодно; пара — только если хотя бы одна из карт родного класса мира
  (значок в углу мира). В Омуте пара — одного класса.
- **Бой** — существа бьют сами в конце хода: того, кто напротив (Приоритет — первым), пустой мир напротив — удар по жизням.
  Пунктирные стрелки показывают, кто кого ударит и сколько снимет. Только что поставленные ждут следующего хода (кроме Рывка).
- **Переставить** — существ, поставленных в этом ходу, можно переставлять сколько угодно до «Конца хода»; потом они закрепляются.
- **Чары** — перетащи на подсвеченную цель; чары без цели — на поле или кнопка «Сыграть».
- **Сжечь** — пока тащишь карту, внизу появляется зона «Сжечь карту»: +1 монета.
- **Усилить** — кнопка над рукой, потом коснись своего существа: +1 к атаке за 2 монеты.
- **Описание карты** — двойное касание (сразу оборот) или долгое нажатие.
- **Время на ход** — 60 секунд по умолчанию (настраивается), потом ход заканчивается сам.
- **Угроза** — красная метка «−N ♥» на твоём пустом мире: столько Бот снимет через него в свой ход.
- Если ходить больше нечем, кнопка «Конец хода» мягко пульсирует.

## Что есть в игре

- **Меню** — лунный пейзаж Нави на весь экран, туман и светлячки, логотип, веер из трёх карт (коснись — описание),
  «Нырнуть», «Как играть», «Бестиарий», шестерёнка — настройки. При первом запуске предлагается обучение.
- **Жребий** (монета «Ты» / «Бот»), сразу раздача, **матч против бота**, **пауза** (Esc или «Назад»), **итог** со статистикой.
- **Анимации** — выпад атакующего, удар с цифрой, рассыпание на пиксели, предсмертный удар красным следом, Кракен
  утаскивает щупальцами, водоворот «Омут поглотил», превращение Бабой-Ягой, огненный шар, монеты в копилку, частицы миров.
- **Бестиарий**, **Как играть**, **обучение** по сценарию, **настройки** (жизни, бот, время хода, скорость анимаций,
  меньше движения, громкость, музыка). Звук синтезируется в браузере.
- Векторные иконки (`src/game/icons.ts`), шрифты Golos Text и Ruslan Display, рендер не ниже ×2 для чёткости.

## Арт

Исходники лежат в `assets/`:
- `assets/cards/front|back/{id}.png` — лицо и оборот 26 карт (из `output/cards-complete`);
- `assets/worlds/{id}.png` — фоны миров. Сейчас настоящие только `yav` и `nav`; для `chasha`, `puchina`,
  `peklo`, `omut` фон рисуется из арта карты этого мира (Кикимора, Морской змей, Огненный шар, Омут поглотил),
  размытого в атмосферу. Сгенерируй настоящие по `docs/art-prompts.md`, положи в `assets/worlds/` и запусти
  `npm run art` — они заменят запасные автоматически;
- `assets/ui/` — аватары, рубашка. Фон меню делается из `assets/worlds/nav.png`.

`npm run art` (Node + sharp) обрезает карты по прозрачным краям, уменьшает их, вырезает фишки
76×80 по лицу персонажа (`TOKEN_FOCUS` в `scripts/art.mjs`), запекает скруглённые углы у фишек и миров,
готовит фон меню. Результат — `public/art/`.

## Структура

```
src/engine/        чистый движок: правила, бот, ГСЧ (без Phaser и DOM)
src/game/core.ts   размеры, зум камеры, палитра, тексты, настройки, стек окон
src/game/audio.ts  синтез звука
src/game/ui/       кнопка, фишка, карта руки, инспектор, эффекты, фон, прокрутка
src/game/scenes/   загрузка, меню, правила, бестиарий, настройки (LayoutScene — сетка этапа 0, ?grid)
src/game/match/    сцена матча, анимации событий, окна матча, обучение, геометрия
```

Поток: жест → `Action` → `engine.apply()` → `events` → очередь анимаций → сверка вида с `state`.
Ввод заблокирован, пока идёт очередь.

## Проверки

```powershell
npm.cmd run build
npm.cmd test
```

Тесты движка (Vitest), сетка этапа 0 (`/?grid`), стенд движка и e2e: полная партия от меню до
итога без ошибок в консоли и старт обучения. Браузерные тесты используют установленный Microsoft Edge.

Откат к состоянию до этой сборки: копия прежних `src/`, `tests/`, `index.html`, `package.json`,
`vite.config.ts`, `README.md` лежит в `output/stage-full/rollback-copy/`.

## Выкладка: GitHub Pages + Telegram Mini App

Сборка статичная (`vite base: './'`), сервер не нужен. Workflow `.github/workflows/pages.yml` собирает игру
и публикует её на GitHub Pages при каждом push в `main`.

1. На github.com создай **публичный** репозиторий, например `omut` (без README).
2. В папке проекта:
   ```powershell
   git remote add origin https://github.com/<логин>/omut.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
   Через 1–2 минуты игра будет по адресу `https://<логин>.github.io/omut/`.
4. Telegram: в @BotFather → `/mybots` → бот → **Bot Settings → Menu Button** → вставь адрес из шага 3,
   название кнопки «Играть». Для отдельной ссылки на игру: `/newapp` с тем же адресом.

В Telegram игра растягивается на весь экран, не закрывается свайпом вниз (он мешал бы перетаскиванию),
кнопка «Назад» Telegram закрывает окна и ставит паузу, на телефонах есть лёгкая вибрация.
